# Meu Portal de Entretenimento Digital

Projeto da Agenda 13 – Desenvolvimento de Sistemas I (ETEC), criado por Luigy Renan.

## Como visualizar
- **Página do site (após ativar o GitHub Pages):** https://renanluigy-png.github.io/meu-portal-de-entretenimento-digital/
- O arquivo `index.html` é a página inicial usada pelo GitHub Pages; `portal.html` é mantido como arquivo principal solicitado na atividade.
- Para editar o projeto, abra a pasta no Visual Studio Code.

### Ativar o GitHub Pages
No GitHub, abra **Settings → Pages**. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch **main** e a pasta **/(root)**, depois clique em **Save**. Aguarde a publicação e abra o link da página do site acima.

## Estrutura
- `portal.html`: estrutura HTML e exemplos de CSS inline e interno.
- `reset.css`: reset inspirado no modelo de Eric Meyer.
- `estilo.css`: estilos externos, classes, IDs e layout com Flexbox.
- `imagens/`: nove ilustrações SVG locais utilizadas nas tags `<img>`.
- `documentacao/registro_interacoes_ia.md`: registro das três etapas de apoio da IA.

## Requisitos atendidos
- CSS inline, interno e externo.
- Classes e IDs para organizar títulos, seções e fontes das imagens.
- Flexbox para organizar as três seções lado a lado em telas grandes, com adaptação para tablets e celulares.
- Comentários explicativos no HTML e nos arquivos CSS.
- `reset.css` vinculado antes de `estilo.css`.

As ilustrações SVG são locais e não exigem conexão externa. Os links dos cartões direcionam para páginas dos serviços mencionados.
